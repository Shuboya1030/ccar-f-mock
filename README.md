# CCAR-F Mock Exam

A free 15-item practice exam for **Claude Certified Architect – Foundations
(CCAR-F)**, available in English and 中文.

**→ [Take the test](https://shuboya1030.github.io/ccar-f-mock/)**

- 15 items, ~10 minutes, no signup
- Covers all five exam domains
- Scored by percent correct, with a per-domain breakdown and a weak-spot list

## About the questions

These are **original items written against the public CCAR-F exam guide
blueprint**. They are not real exam content, and no real exam material was used
to produce them. Real exam questions are covered by a non-disclosure agreement.

## Repository

This repository holds only the built page. It is a single self-contained HTML
file with no backend, no database, and no tracking — your answers never leave
your browser.

Authoring source and tooling live in a separate private repository.
